## Selection and production

These are comparison images, not runtime textures or an exact placement contract.
Each is an unchanged 1672×941 generated PNG. Portrait cropping and minor spacing
vary slightly between concepts; the decision here is the frame treatment and the
shared background. Response wording remains layout copy rather than new screenplay.

Once an option is selected, the production art needs one continuous backing and an
outer frame. The animated portrait can be composited over that backing. The former
portrait aperture, separate backing and vertical divider are superseded by the
owner’s new direction. Existing production files are retained as the previous
delivery until the selected replacement is made. Scrolling and input work can
continue independently of that choice.

`generation.json` records all five built-in image-editing prompts, their common
reference, native image sizes and SHA-256 hashes.

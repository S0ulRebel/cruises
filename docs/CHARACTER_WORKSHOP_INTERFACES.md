## Assembly API

Files: actors/assembly/assembly.gd (CharacterAssembly, @tool Node3D), part.gd
(AssemblyPart, @tool Node3D), operations.gd (AssemblyOperations, RefCounted).
Neither node script builds content or resets transforms on startup.

AssemblyPart exports part_id, source_path, attachment_mode (FREE, PARENT, BONE,
SKINNED), target_path (relative NodePath), bone_name, binding_data (Resource) and
geometry_masks (Array[Resource]). Model child contains the whole imported scene,
including its local rigs and animation. IDs are generated by authoring operations,
never from the model filename. Free assembly works without a skeleton.

Operations below are static. Mutating methods return Dictionary with ok: bool,
error: String; extra fields are documented in the module README. Failures leave
the current scene unchanged. Operations never save unless named save_scene.

- create_part(source_path: String) -> Dictionary; returns part: AssemblyPart off-tree.
- collect_parts(root: Node) -> Array[AssemblyPart].
- nearest_part(node: Node) -> AssemblyPart; null when outside an assembly part.
- ensure_owned(node: Node, scene_root: Node) -> void; explicit authoring only.
- independent_snapshot(root: Node) -> Node; off-tree, fully owned clone retaining
  authored IDs/hierarchy and private mutable resources. Caller frees after packing.
- validate_transform(value: Transform3D) -> String; empty string means valid.
- capture_attachment(part: AssemblyPart) -> Dictionary.
- restore_attachment(part: AssemblyPart, state: Dictionary) -> void.
- attach(part: AssemblyPart, target: Node3D, mode: int, bone: String,
  scene_root: Node3D) -> Dictionary; preserve global placement and reject cycles.
  FREE target is scene_root; PARENT is an arbitrary node; BONE target is Skeleton3D.
  SKINNED conversion uses the separate binding service, not this method.
- duplicate_part(part: AssemblyPart) -> Dictionary; returns independent part off-tree.
- capture_source_composition(part: AssemblyPart) -> Array[Dictionary].
- initialize_source_composition(part: AssemblyPart) -> void; explicit import/adopt
  regenerates nested part IDs and marks the retained source composition boundary.
- restore_source_composition(states: Array) -> void; exact IDs/metadata for undo/redo.
  Duplicate preserves imported nested parts but excludes later separate attachments.
- save_scene(root: Node, output_path: String) -> Dictionary; explicit .tscn path,
  with stable IDs, all authoring metadata, local rigs and authored ownership intact.

Undo is owned by the editor plugin using EditorUndoRedoManager. Core attachment
snapshots retain needed objects; no queue_free during undoable editor operations.
Hide uses native visibility. Removing a part with dependents requires an explicit
UI choice. Native scene-tree operations remain available and saved scenes are usable
without the plugin at runtime.

## Mesh exclusion API

Files: actors/assembly/mesh_exclusion/mask.gd (MeshExclusionMask, @tool Resource),
operations.gd (MeshExclusionOperations, RefCounted).

Mask exports source_mesh: Mesh, topology_fingerprint: String, excluded_faces:
Dictionary (integer source surface -> PackedInt32Array of triangle ordinals), and
source_node_path: NodePath. It preserves the original for reset and cold reopening.
Import topology changes are detected against the fingerprint, not silently remapped.

Static functions return ok/error dictionaries unless otherwise noted:

- fingerprint(mesh: Mesh) -> String.
- validate(mesh: Mesh, mask: MeshExclusionMask) -> String.
- build(mesh: Mesh, excluded_faces: Dictionary) -> Dictionary; mesh: ArrayMesh,
  surface_map: Dictionary (source -> output indices). Keep attributes, skin weights
  and each blend-shape array; discard stale LOD/shadow geometry deliberately.
- faces_in_box(mesh: Mesh, bounds: AABB) -> Dictionary of selected face ordinals.
- ray_face(mesh: Mesh, origin: Vector3, direction: Vector3) -> Dictionary;
  surface/face/distance, or empty dictionary for no hit. Ray is in reference mesh space.

Editor stores masks on AssemblyPart.geometry_masks, applies derived meshes only on
deliberate authoring commands, and restores originals through undo/reset. Explicit
Save/Save As persists outputs. Collision/picking must not use stale excluded geometry.
No source rewriting, automatic Head-weight trimming or runtime reconstruction.

## Binding API (integration)

CharacterBindingService.bind_part(part, donor) prepares `{ok,error,model,
binding_data,skeleton}`. Model is off-tree; the editor swaps it and metadata in one
undo action. binding_data keeps an original PackedScene and source/fit transforms;
rebinding uses original geometry. `bind_part_async(part,donor,progress,cancel)` is
awaitable, reports a fraction and queries cancellation on the main thread. Only
private arrays/read-only weight samples enter the worker. Cancellation/stale input
discards the result without modifying the scene. Facial shapes and unsupported torso
landmarks produce a visible failure before conversion. No implicit fit or rebind.

CharacterAnimationService.borrow(model,source_path) prepares `{ok,error,player,
created,library,model}`. A new player is off-tree; an existing one stays unchanged.
The editor installs the independent `captain` library undoably. Unsupported local
facial rigs fail before humanoid retargeting; attachments still support these rigs.

CharacterActorExportService.export_actor(root,explicit_path) optionally authors a
separate Mover prefab with collision/navigation nodes and an explicit compatible
animation_player_path plus idle/walk names. Competing trees targeting that player
are disabled in the exported copy; separate facial trees remain active. Collision
bounds use drawable geometry, ignoring unused vertices retained by exclusion masks.
Static assembly saves do not add these.

CharacterLegacyOutfitService.prepare(scene_root,path) returns independent off-tree
root parts and visible warnings for Outfit or individual OutfitPiece resources.
Nested pinned parts remain children; all instances are discovered with collect_parts.
Skinned fits need deliberate donor binding. Conversion never overwrites source data.

## Reference workspace

`reference_workspace.gd` keeps per-root session state and saved-scene keys through
injected read/write preference callables. The native dock supplies EditorSettings
project metadata. Context changes load preferences read-only; explicit reference
actions and a same-root Save/Save As path change persist choices. Tests inject a
memory store, leaving the owner's reference preferences untouched.

`reference_board.tscn` owns the thumbnail list/file chooser; `set_context(root)`,
`add_images(paths)`, `set_mode(mode)` and `changed(state)` form the widget boundary.
An open chooser remembers the root and rechecks the actual edited root on acceptance.
`reference_view.tscn` is a normal 2D Control with `set_image`, `fit`, `zoom_at` and
`pan`, not a third SubViewport. The dock toggles the original detail camera and this
image control without altering the assembly. Image paths are not scene metadata.

## Editor and acceptance

Plugin opens an authored empty template, can wrap/add arbitrary source models, lists
scene-derived parts and targets, uses native transforms, and performs undoable
add/duplicate/hide/remove/replace/attach/detach/exclude/reset. User paths are chosen
through dialogs. No fixed categories or slot naming. Animation preview duplicates
mutable animation/material resources; one-shot clips remain one-shot.

Workspace activation is explicit. `_handles` claims character nodes only while
Workshop is already visible. Close Workshop and native 3D/2D tabs hide it, stop
preview animation/shading, restore poses/focus, cancel drags and release face/attach
input. Hidden viewports suspend rendering. Scene switches queue a guarded close
after native per-tab main-screen restoration; explicit New/Open then queues reopening
for the same current root ID. Deferred actions cannot activate a different scene.
Godot's handling main editor selection is documented by its
[editor source](https://github.com/godotengine/godot/blob/4.5/editor/editor_node.cpp).

The editor now uses a main-screen workspace. `dock.gd` coordinates a real hierarchy,
asset drawer and two reusable `workshop_view.tscn` panes. A pane shares the edited
root's World3D and owns its camera/UI outside that root. `set_context`, `set_tool`,
framing, drag cancellation and face-overlay updates are public widget methods.
Requests select native nodes, pick attachment targets or submit `{part,before,after}`
world transforms. Live drags restore their original transform before the commands
boundary records local transforms in native undo; root transforms are also supported.
Inline fine adjustment has the same command boundary, with stale-context validation
and explicit Apply/Cancel. `set_fitting_options` applies World/Local move/rotation,
snap enable and configurable increments; scale remains on the part's own axes.
Cameras, grids, environments and browsing previews never pack
into a saved character. Reference geometry is used to pick posed skinned meshes.

The read-only asset browser discovers imported models/3D scenes from EditorFileSystem,
filters project paths and queues visible thumbnail previews. Requests add explicit
project paths. Missing native previews use one representative visible mesh, inspected
through SceneState without instantiation; preview material overrides affect private
mesh copies only. Explicit import requests validate external GLBs for self-contained
resources, copy them to a chosen project folder without overwrites, and add them
after successful import.
Formats with external dependencies use Godot's normal complete-asset import workflow.

`AssemblyOperations.validate_scene_save(root,path)` performs the existing read-only
save checks, including canonical source-path aliases. Explicit snapshot `save_scene`
uses it before packing an independent copy; the workshop uses it before native
`EditorInterface.save_scene_as(path,false)` to retain the current tab and saved state.
Pending file dialogs retain the character identity; switching scenes cannot save a
different root. No native screenshot/preview request is made by this save route.

Before an explicit native save, editor-only `mesh_storage.gd.store(root,scene_path)`
collects scene-owned mesh resources, including referenced shadow/source meshes, and
writes them to `<scene_path_without_extension>/meshes/`. It retains those explicit
paths with `take_over_path` after ResourceSaver returns; FLAG_CHANGE_PATH alone is
temporary in the engine. Dependencies save before parents. Repeated writes are
limited to files referenced by the existing destination, including nested scene
dependencies; unrelated file collisions reject before overwriting. Source imported
models/textures and source PackedScene definitions are never saved by this service.

The plugin accepts complete `portrait_rig.gd` roots as authoring contexts alongside
assemblies/gameplay actors. Native saves preserve the portrait's camera/lights and
speech target paths. Saving a bare assembly or exporting an actor over an existing
portrait renderer is rejected. The Captain uses a UI-local fitted assembly instance;
its template and game mesh resources have separate files.

Hierarchy requests rename `{part,name}`, context actions `{part,action}` and parent
drops `{part,target}` through the command boundary. Renaming rebases retained
NodePath properties and affected AnimationPlayer tracks in private library copies;
undo restores the original paths/resources. Parent drops use the existing validated
attachment operation. Viewport asset drops carry `{paths,root,world_position}`;
`world_position=null` retains authored placement. Cursor placement only changes the
wrapper origin before insertion, in the same undo action. The origin-marker preview
does not instantiate content. Focus mode restores the prior editor dock visibility.

Check real native editor startup, UI commands and undo; static assembly, independent
copies, local Head/Jaw and blend shapes, transformed parent attachment, save/cold
reload, masked skinned meshes, and native/borrowed locomotion. Script errors fail.

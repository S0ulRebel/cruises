# Captain’s Ledger — five frame variations

11 October 2026. These full-screen concept previews answer the owner’s request to
remove the vertical divider, move **Your response** higher and compare five modest
variations of the outer frame. **The owner selected option 3, rope-edged walnut.** The production source is
[`../../dialogue_frame.png`](../../dialogue_frame.png), with its layout in
[`../../dialogue.json`](../../dialogue.json).

## Selection and production

These are comparison images, not runtime textures or an exact placement contract.
Each is an unchanged 1672×941 generated PNG. Portrait cropping and minor spacing
vary slightly between concepts; the decision here is the frame treatment and the
shared background. Response wording remains layout copy rather than new screenplay.

Option 3 is selected. The final production panel now provides one continuous
parchment backing and a rope/walnut outer frame. The animated portrait is composited
over that backing. The former portrait aperture, separate backing and vertical
divider are superseded. The other four images remain alternatives in this preview
history. Engine integration and runtime input verification remain in HANDOFF.md.

`generation.json` records all five built-in image-editing prompts, their common
reference, native image sizes and SHA-256 hashes.
